# ჩექაუთი

## orderId URL-ში
orderId ინახება მისამართში (/checkout/confirm/:orderId), არა მხოლოდ მდგომარეობაში.
რატომ: კოდის ეკრანზე F5-ზე useState იკარგება, URL კი რჩება.

## ბარათის მონაცემები
ბარათი არსად ინახება: არც localStorage/sessionStorage-ში, არც URL-ში, არც გლობალურ store-ში, არც console.log-ში.
ის მხოლოდ ფორმის მეხსიერებაშია და გაგზავნის შემდეგ ვასუფთავებთ.
სერვერი ინახავს მხოლოდ ბრენდს და ბოლო 4 ციფრს.

## ორმაგი გადახდა
"გადახდა" და "დადასტურება" ღილაკები მოთხოვნის დროს გათიშულია (disabled + loading).

## ორი ნაბიჯი
მიწოდება და ბარათი ერთ ეკრანზეა, შემდეგ კოდის ეკრანი.
